# A New Cut-and-Solve-Based Approach for the Single-Source Capacitated Facility Location Problem

This repository contains the test instances, the detailed experimental results, and source code for the proposed algorithms related to the article "A New Cut-and-Solve-Based Approach for the Single-Source Capacitated Facility Location Problem", submitted for publication in the European Journal of Operational Research.

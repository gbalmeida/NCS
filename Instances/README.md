# Benchmark Instances

This directory contains the five benchmark datasets used in the computational experiments with the NCS algorithm. While all instances are hosted directly in this repository for permanent access and immediate reproducibility, their original references and retrieval sources are detailed below.

---

### TB1 — Holmberg

**Reference:**  
Holmberg, K., Rönnqvist, M., & Yuan, D. (1999). An exact algorithm for the capacitated facility location problems with single sourcing. *European Journal of Operational Research*, 113(3), 544–559.

**Downloaded from:**  
https://or-brescia.unibs.it/instances/instances_sscflp

---

### TB2 — Yang

**Reference:**  
Yang, Z., Chu, F., & Chen, H. (2012). A cut-and-solve based algorithm for the single-source capacitated facility location problem. *European Journal of Operational Research*, 221(3), 521–532.

**Downloaded from:**  
https://or-brescia.unibs.it/instances/instances_sscflp

---

### TB3 — Gadegaard

**Reference:**  
Gadegaard, S., Klose, A., & Nielsen, L. (2018). An improved cut-and-solve algorithm for the single-source capacitated facility location problem. *EURO Journal on Computational Optimization*, 6(1), 1–27.

**Downloaded from:**  
https://github.com/SuneGadegaard/SSCFLPsolver/blob/master/All_instances_for_Imp_CnS.zip (folder `AnImprovedCutAndSolveAlgorithm`)
